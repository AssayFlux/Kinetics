- CI #2159 (`06fa4a5`) failed because the generated Android capability catalogue was stale. Commit `c2dcb64` regenerated it from the canonical registry.

- Commit `ebe2335` adds bounded provenance-aware protein motif scanning; commit `9817acb` adds bounded alignment-aware structure coordinate mapping with tie abstention. Exact-commit CI #2163 for `9817acb` is pending and has not published jobs yet.
- CI/host tests do not prove WebView/device behavior, external model execution, biological accuracy, clinical validity, or wet-lab function.

## Completion rule

S can be closed only when every required software acceptance item has implementation and tests, exact-commit CI passes, and each external gate is either satisfied with auditable evidence or explicitly re-scoped by the owner as a deferred deliverable. A deferred item must remain visible as a blocker and must not be represented as completed capability.

**Current disposition: NOT COMPLETE — keep Track I blocked.** Continue with the next S software acceptance item that can be implemented safely with available repository assets; request owner-supplied/licensed datasets, model approvals, renderer choice or device evidence only when that gate is reached.

## Follow-on implementation — alignment-aware coordinate mapping (2026-11-09)

- Added a bounded semi-global linear-gap aligner for observed structure chains against query-sequence subsequences.
- Only exact residue identities are mapped; non-identical aligned pairs are omitted.
- Optimal-path ambiguity causes abstention; identity and structure coverage thresholds are caller-configurable and recorded.
- Synthetic tests cover internal query insertions, fragment mapping, repeated placements, low identity, noncontiguous numbering and resource limits.
- This does not replace calibrated homology search or independent biological mapping validation.

## Follow-on implementation — S1 offline renderer prototype (2026-11-09)
