# Scientific palettes

**Status:** planned; no palette is yet validated.

Required palette families:
- categorical: distinguishable under common colour-vision deficiencies;
- sequential: perceptually ordered, monotonic lightness;
- diverging: perceptually balanced around a meaningful midpoint.

Each palette must have a machine-readable definition, contrast checks, colour-vision-deficiency simulation output and non-colour encoding (labels/shape/line style). Never use red/green alone for scientific meaning. Validation output is pending; no CVD-safety claim is made.
