# Historical theme proposals — superseded by D-015

**Status:** Retained for historical reference only. These palettes and the dark-first/Obsidian Cyan default are not current product design instructions.

The owner approved the Light Classic Kinetics design on 2026-11-08. Current palette, typography, screen composition and implementation rules are in [the canonical visual design system](kinetics-visual-design-system.md). Current semantic token source is `design/tokens.json`.

The older Porcelain Blue, Ivory Sage, Cloud Lilac, Sandstone Copper, Obsidian Cyan, Midnight Violet, Graphite Ice, Deep Ocean, Carbon Amber and Neon palette definitions remain in the token file for historical compatibility and may not be exposed as active product choices unless separately approved. D-015's Kinetics Light Classic is the default and Kinetics Dark Classic is the dark counterpart. System theme follows platform appearance.

The 26-family typography catalogue remains useful as a set of candidates, but D-015 role selections are Great Vibes (limited brand script), Cormorant Garamond (display), IBM Plex Sans (UI/body) and IBM Plex Mono (scientific data). Verify exact licenses, versions, glyph coverage, font scale and package size before bundling.

No contrast, CVD, device screenshot or font redistribution pass is claimed here.
