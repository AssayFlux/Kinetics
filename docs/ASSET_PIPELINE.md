# Kinetics brand asset policy

## Original brand mark

The original Kinetics guilloche brand artwork is preserved unchanged at:

`Assets/Brand Logo.svg`

The file is restored from its original Git blob; it is not regenerated or redrawn.

## Visual policy

The brand logo is retained as the repository's identity asset. Generated GIF animations, animation builders, animation validators and animation-specific GitHub Actions are not maintained. Scientific data visualizations should be produced by the application at runtime when needed, rather than committed as decorative animation files.
