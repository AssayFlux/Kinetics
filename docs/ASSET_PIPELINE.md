## Maintenance policy

- Do not redraw, recolour, optimize destructively or replace the original brand mark without explicit design approval.
- Keep the four platform shells content-empty until real product capabilities and workflows are defined. Do not add fabricated metrics, scientific results, user records or system states.
- Treat the HTML/CSS layouts as prototypes, not native application binaries or evidence of a working cross-platform application.
- The GIF is a legacy presentation asset, not a scientific visualization pipeline. It remains tracked because the README references it and the asset test checks it. Do not describe it as generated by a maintained animation workflow.
- Scientific plots and structure views must be generated from real data at runtime with provenance, units and uncertainty where applicable.
- Keep the SVG and HTML/CSS assets accessible, responsive and validated. Update this document and the documentation index when asset ownership changes.
